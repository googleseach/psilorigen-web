# PsilOrigen

Bienvenido al repositorio oficial de **PsilOrigen**. 
Un espacio seguro de introspección, sanación y reconexión con tu esencia más profunda.

### 🚀 Tecnologías utilizadas
* HTML5
* CSS3 (Variables, Flexbox, Grid, Animaciones)
* JavaScript (Vanilla)
* Google Apps Script (Backend para formularios)

### 📂 Estructura del Proyecto
* `index.html` - Portada
* `quienes-somos.html` - Filosofía y equipo
* `experiencia.html` - Ciencia y acompañamiento
* `inversion.html` - Aportes y planes
* `reserva.html` - Calendario y formulario paso a paso
* `contacto.html` - Redes y WhatsApp
* `css/styles.css` - Hoja de estilos unificada
* `js/script.js` - Lógica unificada
* `img/` - Recursos gráficos

### 🔧 Instalación local
Simplemente abre el archivo `index.html` en tu navegador. No requiere servidores locales.
