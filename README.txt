=========================================
PSILORIGEN - INSTRUCCIONES
=========================================

1. Coloca manualmente en la carpeta 'img':
   - logo.png
   - foto_meditacion.jpg

2. Abre index.html en el navegador para ver el sitio.

3. Estructura de archivos:
   - index.html          -> Portada
   - quienes-somos.html  -> Quiénes Somos
   - experiencia.html    -> Experiencia
   - inversion.html      -> Aporte (nombre de archivo se mantiene)
   - reserva.html        -> Reserva
   - contacto.html       -> Contacto
   - formulario.html     -> Formulario alternativo
   - css/styles.css      -> Estilos unificados
   - js/script.js        -> JavaScript unificado
   - img/                -> Imágenes

4. IMPORTANTE: En toda la navegación visible, el enlace
   a inversion.html se muestra como "🤲 Aporte".
